# 🚀 InsightFlow AI

> Turn customer feedback into product decisions using AI.

InsightFlow AI is an AI-powered customer research analysis platform that transforms customer interviews, support tickets, surveys, reviews, and feedback into actionable product insights within minutes.

Built during a hackathon, the platform helps product teams understand user pain points, identify recurring themes, analyze sentiment, and interact with their research using an AI-powered workspace assistant.

---

## ✨ Features

### 📂 Project Management
- Create and manage multiple research projects
- Organize customer research efficiently

### 📄 Document Upload
- Upload interview transcripts
- Customer support conversations
- Survey responses
- Product reviews
- Research documents

### 🤖 AI Analysis
Automatically extracts:
- Customer pain points
- Feature requests
- User sentiment
- Product opportunities
- Recurring themes
- Actionable recommendations

### 💬 AI Workspace Assistant
Ask questions like:
- What are the main pain points?
- What features are requested most?
- Summarize this project
- What should we build next?

### 📊 Report Generation
Generate structured reports from customer research for product and business teams.

### 🔐 Secure Authentication
- User authentication
- Protected API routes
- JWT authorization
- Secure data access

### 🛡 Security
- Row Level Security (RLS)
- Rate limiting
- Request validation
- Abuse protection
- Secure file uploads
